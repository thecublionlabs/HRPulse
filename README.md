# HRPulse

Enterprise-style HR Data ETL Platform built using Python, FastAPI, Snowflake, AWS, Docker, Kubernetes, MongoDB, DynamoDB, and AWS Bedrock.

## Project Goal

HRPulse is designed as a professional end-to-end HR analytics platform that:

- Ingests HR CSV/JSON files
- Validates and transforms HR data
- Builds RAW → STAGING → MART pipeline
- Exposes REST APIs using FastAPI
- Integrates GenAI insights using AWS Bedrock
- Stores logs and metadata
- Runs using Docker and Kubernetes
- Deploys through GitHub Actions CI/CD
